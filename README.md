# 奥德赛手记 · The Odyssey Journal

**面向“奥德赛时期”、正在求职或初入职场青年的 AI 职业规划与 Life Coach 工具。**

从校园走向职场时，方向、身份和生活节奏可能都还在探索。奥德赛手记通过引导访谈，帮助你回看成长经历与实际反馈，认识能力长板、价值观和现实约束，比较职业选择，并把长期方向拆成可以尝试和复盘的行动。

它提供两种相互配合的支持：

- **职业规划教练**：梳理技能和作品证据，比较求职与发展路径，制定近期行动和长期探索计划。
- **Life Coach（成长陪伴）**：探索动力、生活偏好、家庭影响与重要转折，帮助你形成自己的判断和行动节奏。

经历、作品与真实反馈是建议的主要依据；MBTI 用来提出待验证的假设，星盘与八字仅作自愿的象征性反思。所有画像都可以由你核对、纠正，再生成发展地图。

当前版本为免费开源的网页工具，支持自带模型接口（BYOK）。其访谈与规划流程也为未来封装成 Agent Skill 提供基础；目前尚未提供可直接安装的 Skill 包。模型调用费用由用户与所选服务商结算。

## 使用

1. 运行 `node server.mjs`，打开 http://127.0.0.1:4173 。需要 Node.js 20 或以上。
2. 可先浏览虚构示例，无需接口。
3. 设置支持 Chat Completions 格式的 HTTPS 接口地址、模型名称和自己的 API Key。服务商需允许浏览器跨域请求；并非所有接口支持。不要使用不可信中转站。
4. 完成访谈，预览即将发送的内容，确认后生成画像；纠正画像后生成地图。
5. 可导出 Markdown、通过浏览器打印为 PDF，或导出 JSON 备份。

## 隐私与边界

- 无业务后端、无分析追踪；PDF、DOCX、TXT、Markdown 在浏览器本地提取文字，原文件不上传。
- 每次发送前显示接收端点、模型和完整内容。选中的内容会发送给用户选择的模型服务商。保存在本机，不代表模型服务商没有收到内容；其留存政策由该服务商决定。
- API Key 仅在当前页面内存中，刷新即清除；进度仅在用户选择后存入浏览器。共享设备请清除资料，下载的备份仍需自行保管。
- MBTI 只提出待验证假设；星盘、八字为可选的文化和叙事探索，不作为能力、健康或命运的事实证据，不自动计算或编造排盘。
- 家庭经历可跳过，不能据此诊断人格或心理疾病。地图是可修订的实验计划，不是确定预测。
- 模型调用费用由用户与其服务商结算；静态网页不意味着模型免费。

## GitHub Pages

本发布包使用 `docs/` 保存网页代码，不依赖 Actions 工作流。
上传本文件夹内的全部文件与子文件夹到仓库根目录，然后进入 Settings → Pages：
Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /docs，点击 Save。
GitHub 完成部署后，此页面会显示公开网址。

## 测试

运行 `node --test tests/*.test.mjs`。测试覆盖资料白名单、发送同意快照、模型响应校验、密钥隔离和异步文件任务失效。浏览器流程已用模拟接口验证；使用前仍需验证所选服务商的跨域与模型支持。
